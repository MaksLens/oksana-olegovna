# Сайт репетитора Оксаны Олеговны — версия 2

Вторая версия сайта: новый дизайн, SVG-персонажи и анимации. Первая версия лежит в ветке `main`, эта — в ветке `v2`.
Статичный сайт без сборки и библиотек: всё открывается из `index.html`, стили в `v2.css`, анимации в `v2.js`.

## Что где

- Фото: `assets/photos/` (портрет, награждение, выступление, итоги конкурса, фестиваль)
- Дипломы и грамоты: `assets/awards/`, уменьшенные копии для карточек — `assets/awards/thumb/`. Номера дипломов размыты.
- Переписки с учениками: `assets/reviews/review-01.webp` … `review-07.webp` (без имён и аватарок в шапке)
- Научные статьи: `articles/` и `assets/articles/`
- Контакты и ссылка на Авито: объект `window.CONTACTS` в конце `index.html`

Страница закрыта от поисковиков (`<meta name="robots" content="noindex">` в `index.html`) — убрать, когда версия станет основной.

## Как опубликовать

Settings → Pages → Build and deployment → Deploy from a branch → `v2` / `(root)` → Save.
Через 1–2 минуты сайт откроется по адресу `https://<имя-аккаунта>.github.io/<имя-репозитория>/`.
GitHub Pages показывает одну ветку на репозиторий: чтобы обе версии работали одновременно, вторую нужно перенести в отдельный репозиторий.
