# Сайт репетитора Оксаны Олеговны

История и обществознание, ОГЭ и ЕГЭ. Статичный сайт без сборки и библиотек: всё открывается из `index.html`.

## Что заменить перед показом клиентам

- Фото: `assets/photos/tutor-hero.webp` и `tutor-01.webp` … `tutor-06.webp` (пропорции 4:5)
- Документы: `assets/awards/award-01.webp` … `award-07.webp`
- Скриншоты отзывов: `assets/reviews/review-01.webp` … `review-08.webp`
- Контакты и ссылка на Авито: объект `window.CONTACTS` в конце `index.html`
- Истории учеников сейчас примеры, их нужно заменить настоящими
- Убрать `class="draft"` у тега `<html>`: пропадут жёлтые пометки

Файлы с такими именами встают на место сами, код менять не нужно.

## Как опубликовать

Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)` → Save.
Через 1–2 минуты сайт откроется по адресу `https://<имя-аккаунта>.github.io/<имя-репозитория>/`.
